# RT  -  Fortran legacy code

----------------------------------------------
Instructions for using the RT code
Author -- Pratik Joshi (ppjoshi2@illinois.edu) and Michal Ondrejcek (ondrejce@illinois.edu)
----------------------------------------------

Follow the following steps to compile and run the 3-part RT code for optically thick analysis of 
NASA's Carruthers Geocorona Observatory mission -- 

This is a legacy Fortran code which is being used for generating Test input and output **DAT** files. Any change 
in the Fortran wrapper code should be also made here and vice versa. 

## Forward model

### Inputs

1) **INPUT_HDEN.txt** - H density parameters Hexo (D_EXO), Hydrogen flux, Solar flux (FLUX_C - used in LOS part only) 
Hydrogen model (IGEO, 0=Chamberlain, 1=Bishop), F107, Hpeak2 etc.:

```
MOD_MSIS  D_EXO (h_exo)  FLUX (H flux)  D_MAX  FLUX_C (solar flux)
IGEO (H model - 0 Chamberlain, 1 Bishop)  SATT  SATD  ALT_MAX  F107
```
   
```
1 100000.0 253602354.0 318043322.0 700000000000.0 
0 750.0 700000.0 80.0 0.0
```

2) **alt_file_LR.DAT** - grid, LR - low resolution, currently 32 values in km: 

```
74.5, 76.0, 78.5, 82.0, 86.5, 92.0, 98.5, 106.0, 116.5, 133.5, 161.0, 205.5, 277.5, 394.0, 582.5, 887.5, 1381.0, 
2179.5, 3471.5, 5562.0, 8945.0, 14417.0, 23273.0, 37601.0, 60785.0, 98299.0, 158999.0, 257199.0, 416109.0, 
673219.0, 1089229.0, 1762329.0
```

inputs to **global_parameters.f** even though they are not being used in either Forward part (**lyao_rt.f**) or in 
los part (**lyao_los.f** and **driver_los_lyao_x**).

3) **rt_bkg.txt**
4) **thermo_bkg.txt**

Two background files are generated by part 1 of RT code (Python) separately.

### Run

1. Change the directory to the RT folder directory
   
```
cd /path_to_RT_code_folder
```

2) Compile the forward model executable.

```
gfortran subroutines_lyao.f corona.f global_parameters.f lyao_rt.f -o forward.out
```

3) Run the forward model

```
./forward.out
```

### Output

**LYAO_source.DAT** - file with the source functions on user-defined RT grid. This complex Fortran generated file
is an input to part 3, LOS model.

## LOS model

### Inputs
1) **LYAO_source.DAT**
2) **orbitinfo.txt** file -- this file should be copied in this folder after running the viewing spacecraft geometry 
code in the Carruthers SDOC pipeline

    a) **orbitinfo_1x.txt** - LOS geometry angles and distance for 1D NFI profile (1024 x 1)
 
    b) **orbitinfo_NFI.txt** - LOS geometry angles and distance for NFI 2D image (1024 x 1024)
    
    c) **orbitinfo_WFI.txt** - LOS geometry angles and distance for WFI 2D image (512 x 512)

   Note: This step includes `global_parameters.f` file which needs following inputs from Forward model:
   **INPUT_HDEN.txt**, **alt_file_LR.DAT**, **rt_bkg.txt**, **thermo_bkg.txt** 
   

### Run

1) Change the directory to the RT folder directory
   
```
cd /path_to_RT_code_folder
```

2) Compile a separate LOS executable for the desired viewing geometry (orbitinfo.txt file) and LOS execution (sequential/parallel).
```
>> gfortran subroutines_lyao.f lyao_los.f corona.f driver_los_lyao_1x.f global_parameters.f -o los_1x.out
>> gfortran subroutines_lyao.f lyao_los.f corona.f driver_los_lyao_NFI.f global_parameters.f -o los_NFI.out
>> gfortran subroutines_lyao.f lyao_los.f corona.f driver_los_lyao_WFI.f global_parameters.f -o los_WFI.out
```

3) Run the slow sequential LOS code as a Fortran executable. 

```
./los_1x.out 
./los_NFI.out 
./los_WFI.out
```

## Forward and LOS model shell script

The most convenient way is to run one of the **build_x.sh** scripts for both,Forward and LOS parts.

```
./build_1x.sh
./build_nfi.sh
./build_wfi.sh
```
which creates both executable (**.out**) files.

### Outputs

**lyao_los_1x.DAT** -  file with the model LOS radiance for geometry of orbitinfo_1x.txt
**lyao_los_NFI.DAT** -  file with the model LOS radiance for geometry of orbitinfo_NFI.txt
**lyao_los_WFI.DAT** -  file with the model LOS radiance for geometry of orbitinfo_WFI.txt
