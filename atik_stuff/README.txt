Atik Cameras

This SDK contains libraries for Windows, macOS, Linux and ARM it also contains the drivers needed for Windows.

We provide two Visual Studio projects as an example of how to use our cameras. The C++ example also contain a makefile for use on linux.

The SDK documentation, located in the "documents" folder, contains instructions for installing dependencies and using the methods available to control Atik Cameras.

Please contact support@atik-cameras.com if you have any issues with the SDK
